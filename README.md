# 로봇 격납고 · 습관 조립 게임

6살 아이를 위한 가정 육아 습관 웹앱입니다. 좋은 습관으로 로봇 부품을 모으고, 나쁜 습관 시 냉각 모드(보상 지연)가 걸립니다.

## 실행

```bash
npm install
npm run dev
```

모바일에서는 같은 Wi‑Fi의 PC에서 `npm run dev -- --host` 후 표시된 주소로 접속하거나,
배포된 사이트에서 바로 실행할 수 있습니다.

**모바일 웹 주소:** https://namchon01.github.io/eidenedu-game/

## 주요 기능

- 메인 격납고: 3D 카봇 + 에너지/냉각 상태바
- 오늘의 미션: 7개 미션이 각각 도장 3개를 모으는 복수 목표
- 미션 카드 안에서 바로 기록: 도장 아이콘을 누르면 색이 채워지고, 채운 도장을 다시 누르면 차감
- 미션 1개 = 부품 1개: 도장 3개를 채우는 순간 그 부품이 3D로 날아와 결합
- 정비소(자유 해체·조립): 부품을 탭하면 분리되고, 끌어다 제자리에 놓으면 스냅 결합
- 사령관 모드: 자물쇠 2초 길게 누르기 → PIN(기본 `1234`), 미션 도장 `+`/`−` 조정
- 히어로 출동식(빵빠레) + 실물 보상 상점(메시지 표시창 · 미션 진행 현황)
- 상태 저장: `localStorage`

## 미션과 부품 대응

| 미션 | 부품 |
| --- | --- |
| 골고루 먹기 | 건강의 심장 |
| 장난감 정리 | 정리의 발 |
| 존댓말 쓰기 | 존중의 머리 |
| 떼 안 쓰기 | 침착의 방패 |
| 과제 제때 하기 | 약속의 다리 |
| 부모님 도와주기 | 도우미의 팔 |
| 일기·편지 쓰기 | 기록의 날개 |

도장은 하루 단위로 초기화되지 않고 계속 누적되므로, 하루에 하나씩 모아 부품을 완성할 수 있습니다.
에너지 게이지는 전체 도장 21개 중 모은 개수의 비율이라 도장 하나마다 조금씩 올라갑니다.

## 3D 로봇과 음향

로봇은 외부 모델 파일 없이 `three.js` 원시 도형을 조합해 코드에서 조형하며,
부품마다 개별 제어가 가능해 해체·조립 놀이에 쓰입니다.

- 아직 획득하지 않은 부품은 반투명 홀로그램으로 표시됩니다.
- 정비소에서 분해해도 미션으로 모은 진행도(`state.parts`)는 바뀌지 않습니다.
- 효과음은 `src/audio/soundEngine.ts`에서 Web Audio API로 합성합니다(음원 파일 없음).
  사령관 모드의 소리 토글과 연동되며, 브라우저 정책에 따라 첫 터치 시 활성화됩니다.
- 도장 +1은 `tap`, 차감은 `detach`, 부품 결합은 `servo → clank → lock → powerUp`,
  7부품 완성은 `fanfare`(빵빠레)로 이어집니다.
- WebGL을 쓸 수 없는 기기에서는 기존 2D 로봇으로 자동 전환되고,
  `prefers-reduced-motion` 설정 시 부유·회전 연출을 줄입니다.

3D 화면 동작을 브라우저에서 점검하려면 개발 서버를 띄운 뒤 다음을 실행합니다.

```bash
node scripts/check-robot3d.mjs
```
