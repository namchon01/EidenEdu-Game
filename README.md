# 로봇 격납고 · 습관 조립 게임

6살 아이를 위한 가정 육아 습관 웹앱입니다. 좋은 습관으로 로봇 부품을 모으고, 나쁜 습관 시 냉각 모드(보상 지연)가 걸립니다.

## 실행

```bash
npm install
npm run dev
```

## 주요 기능

- 메인 격납고: 5등분 로봇 실루엣 + 에너지/냉각 상태바
- 오늘의 미션: 편식 없이 먹기, 정리, 존댓말, 떼 안 쓰기, 과제, 돕기, 일기
- 부품 도킹 애니메이션
- 사령관 모드: 자물쇠 2초 길게 누르기 → PIN(기본 `1234`)
- 히어로 출동식 + 실물 보상 상점
- 상태 저장: `localStorage`

## 기술

React + Vite + TypeScript + Tailwind CSS
